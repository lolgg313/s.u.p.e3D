# s.u.p.e3D
FPS Creator v2.0 is a web-based 3D game engine built with Three.js. It offers seamless Edit and Play modes for designing maps, placing custom .GLB models, and configuring enemies. Optimized with instanced rendering and object pooling, it features custom audio, trigger zones, and JSON map saving.
